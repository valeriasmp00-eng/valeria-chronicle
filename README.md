# The Valeria Chronicle

Server guide for the Guild of Valeria, a Minecraft MMORPG roleplay server: the guild, the
character roster, jobs and progression.

It's a plain static site, no build step. Open `index.html` or serve the folder with anything.

- `index.html` – all the pages and character sheets
- `style.css` – styling
- `script.js` – tabs, the cover page, and the character sheet viewer
- `img/` – artwork
- `ui/` – book, parchment and button textures
- `skins/` – Minecraft skins and custom models used by the 3D preview

The 3D preview uses [three.js](https://threejs.org/) and [skinview3d](https://github.com/bs-community/skinview3d),
loaded from a CDN.
